# Contributing

Thanks for helping improve this project-agnostic development template.

## Before contributing

- Read `AGENTS.md`, `SECURITY.md`, and `PRIVACY_AND_PUBLICATION.md`.
- Keep contributions reusable across unrelated projects and technology stacks unless a section is explicitly labelled as stack-specific.
- Do not submit personal information, private conversations, credentials, confidential material, or content copied from private projects.
- Confirm that you have the right to contribute the material and that its licence is compatible with the repository's MIT licence.

## Workflow

1. Create a focused branch from the current default branch.
2. Explain the problem and intended reusable outcome.
3. Make the smallest coherent change.
4. Review the complete diff for privacy, security, correctness, clarity, and licence concerns.
5. Run relevant checks and state what was not tested.
6. Open a pull request with context, risks, and validation evidence.

Do not merge your own or another contributor's changes without the required review and authorization.
