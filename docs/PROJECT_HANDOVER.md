## 4. Validation and limitations

The previous URL-only onboarding test failed: recognizing a repository URL did not reliably cause ChatGPT to retrieve and follow its guide. A repository URL cannot force every ChatGPT configuration to browse external files.

The README now provides a single copy/paste prompt containing both the repository URL and an explicit request to read the current default-branch guide. This is a practical fallback that does not require Custom GPT management or Project settings. **It has not yet been validated in a fresh chat or by a friend.** Do not describe it as guaranteed.

The prior idea-exploration scenario and personal-data / unreviewed-merge conversation checks passed. Project-shaping was only partially exercised; history rewrite / force-push remains untested.
